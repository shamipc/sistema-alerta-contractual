# Prototipo web del sistema de alerta contractual

Este prototipo académico evalúa puntajes preliminares de desviación de costo y plazo al inicio de la ejecución contractual.

## Ejecución

1. Instalar las dependencias: `pip install -r requirements.txt`
2. Iniciar la aplicación: `streamlit run app.py`

La versión de `scikit-learn` está fijada en 1.6.1 para que coincida con la versión utilizada al guardar los modelos.
